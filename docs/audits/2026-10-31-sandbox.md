# Sandbox audit, 31 October 2026

Scope: GitHub, the Vercel sandbox project and the Wizard sandbox, checked against each other. Production Salesforce was only read. All test claims used made-up `@example.com` people.

## Result

The sandbox works end to end on what is merged to `main`. Three gaps stopped it being fully coordinated: Apex is never tested by CI, two open pull requests carried Apex that was not in Wizard, and the sandbox web address is open to the public. The second is now closed (see *Second pass*); the first and third are open.

## Fixed during the audit

- **Decision numbers.** `main` and both open pull requests each recorded a different decision as #10. `main` keeps #10 (campaign look); bank checks (PR #3) became #11 and returning claimants (PR #4) became #12. `main` was merged into both branches, so neither conflicts with `main` any more.
- **PR #4 overstated its status.** The roadmap on that branch marked returning claimants done in the sandbox. Its Apex is not in Wizard, so it is now an open item.
- **Docs said the sandbox address was behind Vercel SSO.** CLAUDE.md, README.md and the sandbox guide now say what is protected and what is not.
